# 会话主线(Session Thread)

**本文件是 skill 打通的关键** —— 规定大师在**阶段之间**必须传递什么,把 Phase A → B → C → 出口的用户体验串成一条线,而不是四个孤立的对话段。

## 为什么需要主线

未打通的 skill 长这样:

- Phase A 用户说"胸口堵着一团热的湿棉花"
- Phase B 大师问"你想画什么颜色/形状?" —— **好像忘了刚才那句话**
- Phase C 大师说"我注意到你画了一团红" —— **没连回"热的湿棉花"**
- 出口给了个通用小练习 —— **跟用户特定意象无关**

用户感觉:每个阶段都是一次重启,不像被同一个人陪着走了一段。

打通后:

- Phase A 用户说"胸口堵着一团热的湿棉花"
- Phase B 大师说"你刚才说的那团**热的湿棉花**,我们让它有个形状 —— 它是均匀的一团,还是有几层?" —— **顺着继承**
- Phase C 大师说"这团红 —— 你在最开始说过'热的湿棉花',它现在看起来湿吗?还是变干了?" —— **回到原意象**
- 出口小练习跟用户的意象接续:"如果你想留一个仪式:今天回家如果又觉得胸口那里堵,试着**给它换一种湿度**"

## 需要传递的东西(用户词的分层收集)

大师在**Phase A 倾听全程**内存态维护 3 类"用户词",作为主线燃料:

### 1. 身体词(Body Words)—— 用户用来定位身体感受的词

例:"堵在胸口""喉咙紧""胃里翻""肩膀沉""腿软""脑袋炸"

**来源**:现象 1(定位提问)的回答

**用途**:
- Phase B 意象引发时,作为**第一句提示**("你说的那个'堵在胸口',我们让它有个形状")
- Phase C 观察反馈时,作为**回环锚**("你在最开始说过'堵在胸口',现在这团 { 视觉元素 } 是那个吗?")

### 2. 具象词(Concrete Descriptors)—— 用户用来描述感受质地的词

例:"热的湿棉花""凝固的巧克力""刚下过雨的柏油路""一团散不开的雾""一根紧绷的橡皮筋"

**来源**:现象 2(具象化)+ 现象 3(命名)的回答

**用途**:
- **Phase B 意象引发直接跳过重来 —— 这些词已经是 elicitation 的燃料**。大师说"你说的'热的湿棉花',我们让它可视化 —— 主色是什么?形状是均匀的还是有层?"
- Phase B prompt 翻译时,内部 prompt 直接吸收这些描述("dense damp red mass with warm-cold contrast, like humid cotton")
- Phase C 观察反馈的核心锚点(现象学镜子)

### 3. 关键短语(Signature Phrases)—— 用户反复出现或情感浓度高的短语

例:"就这样吧""我不知道怎么办""其实我没事的""我妈总是说 X""我一直在等一个 X""我明明应该 X"

**来源**:整个 Phase A 观察,不是专门提问出来的

**用途**:
- **Phase C 观察反馈**可以引用一次(不多次,一次即可):"你刚才说了一句'我明明应该 X' —— 这张图里,你觉得哪部分是'应该'的样子,哪部分是'不是应该'的样子?"—— 让画面帮用户看清自己的关键短语
- Phase C5 takeaway 的"一句话反馈",往往从关键短语反射而来:"你今天说'我明明应该 X',我想跟你说:也许今天到这里,你可以先不'应该'一次"

### 收集节奏

- Phase A 每轮结束,大师**内部**(不告诉用户)默默维护这 3 类词的列表
- 不需要写到文件里,内存态就够
- 一次会话身体词/具象词各 1-3 个够用,关键短语 1-2 个即可
- **不要过度采集**变成"记者式对话"

## 阶段间传递规则

### Phase A → Phase B(开方后)

**传递内容**:身体词 + 具象词

**做法**:

1. 用户选定艺术形式后,大师**首句必须回到用户的具象词**,而不是从头问 elicitation:
   > "你选了曼陀罗。那我们让你说的**'热的湿棉花'**成为这个圆的中心 —— 它是什么颜色?"
2. 如果用户在 Phase A 没给出足够的具象词(比如只到了身体词层面就开方了),大师在 B1 意象引发时**优先在用户已给的词上深化**,而不是重开一套问题:
   > "你说堵在胸口 —— 那团东西是热的还是凉的?"("热的还是凉的"来自 body-atlas 现象 2)
3. 如果场景是 emotion-palette(纯抽象色彩),用户 Phase A 描述的"热的湿棉花"这种词几乎可以直接翻译成 prompt(dense damp warm color field with cotton-like texture),**不需要再问一遍**

### Phase B → Phase C(选定图后)

**传递内容**:具象词 + 用户在 Phase B1 又新加的意象元素

**做法**:

1. Phase C1 用户先讲后,C2 观察反馈时,agent 挑的观察点**必须至少有 1 个能回连到用户 Phase A 的身体词/具象词**:
   > "我注意到你放在中央的那团红 —— 你在最开始说'胸口堵着一团热的湿棉花'。你看这团红,它还'湿'吗?"
2. 如果 Phase B 生成的图跟用户 Phase A 的描述**明显有偏差**(比如用户说"热的湿棉花"但生成图偏干、偏冷),这个偏差本身就是观察点:
   > "有意思 —— 你说的是'热的湿棉花',但你选的这张里更多是干的、有点凉。你自己看到这个变化,身体哪里有反应?"
3. **禁止**:大师完全忽略用户 Phase A 的话,只从图本身讲

### Phase C → 出口(takeaway)

**传递内容**:关键短语 + 具象词 + 用户在 C2 说的最新回应

**做法**:

1. Takeaway 的**一句话反馈**从关键短语反射而来(见上文第 3 类)
2. Takeaway 的**小练习**要跟用户的具象词/意象接续:
   - 用户核心意象是"热的湿棉花" → 练习可以是"如果今晚又堵起来,试着**改一下湿度或温度**(想象把它变干、变凉,或者往身体外抖一抖)"
   - 用户核心意象是"内在小孩坐在窗边" → 练习可以是"睡前问自己一句:'那个坐在窗边的孩子,今天她需要什么?'"
3. **禁止**:takeaway 给一个跟用户会话完全无关的通用练习(那样就白做 Phase A/B/C 了)

## 大师视角的"回环句式"

主线打通的关键是**回环句式** —— 大师说话时经常"回指"用户之前说过的东西。示例:

- "你刚才说过 '{ 用户原话 }'——你现在看这里,还是那个感觉吗?"
- "回到你最开始说的 '{ 用户原话 }',这张图里哪一处最像它?"
- "'{ 用户原话 }' 这个词今天你说了两次 —— 你自己听到自己这么说,身体哪里有反应?"

**使用节奏**:

- 每个 Phase 里**至少用 1 次**回环句式
- 一次会话总回环次数 3-5 次够,不多做
- 回环要**用户原话**,不要 paraphrase("你说'胸口堵着'" ≠ "你说过你胸口不适")

## 大师应避免的破环行为

- ❌ 每 Phase 开始都重问一遍情况("你今天感觉怎么样?" —— Phase B 开头再问一次这句话就是灾难,前面白聊了)
- ❌ Phase C 观察反馈完全从图本身讲,不带回 Phase A
- ❌ 出口给完全通用的建议,忽略这次会话特有的东西
- ❌ 用户 Phase A 说的具象词,Phase B 意象引发时改用 skill 内部术语("你说的那个 felt sense" —— 用户没这么说过)
- ❌ 大师"记不住"用户说过的话("你刚才说的是什么来着?")—— skill 内部一定要维护词列表,防止真忘

## 引用关系

- **Phase A 结束前**大师读本文件"传递内容"部分,确认已收集足够词
- **Phase B 开始时**读"Phase A → Phase B"段
- **Phase C 开始时**读"Phase B → Phase C"段
- **Phase C5 出口时**读"Phase C → 出口"段
- **回环句式**是全程可用的工具,不需要专门阶段读
