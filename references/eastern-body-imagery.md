# 东方身心意象扩展

本参考把中医与道家文化中的部分概念转译为**身体描述和艺术意象工具**。它不提供辨证、诊断、处方、穴位、经络教学或练功教程。

- 何时加载与使用顺序

## 何时加载

仅在以下情况加载:

- 用户自然使用"堵、沉、散、往上冲、冷、热、空"等身体语言
- 用户明确偏好中医、东方、五行、四时或阴阳意象
- Phase B 需要把身体感受转译为画面方向、材质、节奏或空间关系
- Phase C5 需要筛选一个安全、日常、可选的身体收束动作

用户没有表现出兴趣时,不要主动讲中医或道家理论。一轮最多使用一个东方意象入口,不要展示知识体系。

## 使用顺序

1. **先复述用户原话**:只从用户已经说出的感受开始。
2. **只给一个可撤回的意象问题**:使用"像不像""如果借一个说法",不使用"这说明"。
3. **让用户决定含义**:用户说不像就立即放下,不辩解。
4. **转译成艺术变量**:方向、位置、密度、边界、温度、明暗、材质、节奏。
5. **不从意象反推身体或人格**:艺术选择不是诊断证据。

## 1. 阴阳作为动态轴,不是人的标签

不要说"你偏阴/偏阳""你阴阳失衡"。只把成对变化当作当下体验的坐标:

| 动态轴 | 可用问法 | 可转译的艺术变量 |
|---|---|---|
| 向内 / 向外 | "它更像往里面缩,还是想往外出去?" | 中心/边缘、收缩/扩张 |
| 聚拢 / 散开 | "这些东西聚成一团,还是散得到处都是?" | 密度、留白、碎片数量 |
| 上升 / 下沉 | "它是往上顶,还是一直往下坠?" | 画面方向、重心、旋律走向 |
| 打开 / 合上 | "它有一点想打开,还是更想合起来保护自己?" | 开口、边界、包裹结构 |
| 温 / 凉 | "如果只说体感,它偏温还是偏凉?" | 由用户指定色彩和材质,不自动映射红蓝 |
| 动 / 静 | "它在动,还是像凝住了?" | 动画幅度、笔触、音乐节奏 |
| 明 / 暗 | "它愿意被看见多少?" | 光线、对比度、遮挡程度 |

这些轴没有好坏,目标也不是强迫用户从一端移动到另一端。先允许它保持原样。

### 开、合、转折

可把"开、合、转"作为构图动作:

- **开**:向外延展、出现缝隙、允许光或空气进入
- **合**:收拢、包裹、形成边界,也可能是在保护
- **转**:方向尚未确定、两股力量交汇、停在一个拐点

不要使用六经名称,不要从"开合"推断病位或证型。

## 2. 五行作为开放的材料库

五行只能提供创作入口,不能给情绪贴固定标签。先问用户哪个元素有感觉,再追问它对用户自己的意义。

| 元素 | 可探索的视觉语言 | 可用问法 |
|---|---|---|
| 木 | 生长、方向、枝条、弯曲、韧性 | "它像一根想长出去的枝,还是一截暂时不动的木头?" |
| 火 | 温度、可见度、闪烁、靠近与距离 | "这团火希望被看见,还是只想留一点小小的亮?" |
| 土 | 承托、重量、容器、地面、层积 | "它需要一块地接住,还是本身就像一块很重的土?" |
| 金 | 边缘、硬度、切面、反光、清晰度 | "它的边缘锋利、钝,还是根本没有边界?" |
| 水 | 深浅、流动、停滞、渗透、倒影 | "它是能流的水,还是一片不动、看不见底的水?" |

禁止说"木代表愤怒""肺对应悲伤,所以你的肺有问题"。传统对应关系最多作为可拒绝的联想入口,用户的个人联想永远优先。

## 3. 四时作为时间感和场景感

四时意象适合意象风景、曼陀罗外圈和引导冥想:

- **春**:萌发、试探、刚出现的方向
- **夏**:展开、照亮、被看见、活动增加
- **秋**:收集、筛选、边界变清楚、允许落下
- **冬**:隐藏、保存、休息、等待,不等于消极

问法示例:

> "如果这幅画有一个季节,它更接近哪个?不是分析你,只是帮画面找到空气和时间。"

不要根据现实月份替用户选季节,也不要由季节推出养生、饮食或治疗建议。

## 4. 身体节律 check-in

当用户主动提到睡不好、吃不下、疲惫、呼吸急或明显冷暖感时,可做一次简短 check-in。它只用于决定**本次会话的节奏与模态剂量**,不用于判断健康状态。

一次只问一个最相关的问题:

- "昨晚的睡眠,让你今天还有多少力气留在这段对话里?"
- "你现在的呼吸是急、浅,还是只是有点不顺?"
- "这种冷/热是你当下真实感觉到的,还是更像一个画面比喻?"
- "你想继续探索,还是把今天缩短一点?"

据此只做体验层调整:

- 精力很低 → 缩短对话,优先纯文字或单张静态图
- 明显烦躁或睡眠不足 → 不做激活性视频、强节奏音乐或长冥想
- 呼吸不适 → 不做呼吸训练;鼓励回到自然呼吸,必要时寻求医疗帮助
- 冷暖感强 → 询问用户想用什么颜色/材质表达,不替用户映射

不要询问脉象、舌象、二便、月经或性功能,不要套用所谓"健康标准"。

## 5. 从身体语言到多模态产物

优先按下面顺序翻译,不直接把中医术语写进生成 prompt:

| 用户语言 | 先追问 | 可能的视觉/声音变量 |
|---|---|---|
| 堵 | 堵在哪里、边界多硬、有没有缝 | 压缩构图、窄通道、低频持续音 |
| 散 | 是轻松散开还是失去抓手 | 碎片、宽留白、稀疏音符 |
| 往上冲 | 速度、温度、是否碰到边界 | 上行线条、顶部重心、渐强但不过载 |
| 往下沉 | 有重量还是有安定感 | 低重心、厚材质、缓慢下降音型 |
| 冷 | 是触感还是颜色联想 | 由用户决定色彩;可用玻璃、雾、金属等材质 |
| 热 | 是燃烧、闷住还是温暖 | 由用户决定明暗、扩散范围和节奏 |
| 收拢 | 是保护、休息还是被困 | 包裹结构、同心层、近距离声音 |
| 打开 | 想打开多少、向哪里开 | 缝隙、地平线、空气感、逐渐增加的空间 |

同一个词可能有相反意义。"沉"可以是压抑,也可以是安定;"合"可以是封闭,也可以是保护。必须让用户说出属于 ta 的版本。

## 6. 安全的传统动作筛选

Phase C5 仍优先使用与本次意象 1:1 对应的仪式性小行动。只有用户想要身体动作,且没有表达疼痛、眩晕、呼吸困难、行动障碍或其他医疗风险时,才从 `dialogue-flows.md` 4.8 选 **1 个**低强度动作。

动作前说明:

> "这不是治疗动作。你如果愿意可以轻轻试一下;任何不舒服就停,不需要做满次数。"

禁止引入:

- "排毒/逼毒"、打通经络、调理脏腑、扶阳祛邪等疗效叙事
- 易筋经成套练习、强力绷紧、憋气、提肛、极限拉伸或高重复次数
- 穴位按压、针灸、艾灸、拔罐、刮痧、放血
- 内丹、大周天、守窍、开顶、雷法或宗教观想
- 以"传统上有效"替代风险说明

## 7. 命名人物与临床体系的边界

用户说"用倪海厦的方式看看我"时,先分流意图:

- **想做情绪陪伴/艺术探索**:说明这里不模仿临床诊断,可借用升降、开合、冷暖、五行、四时等意象继续。
- **想要六经辨证、方药、针灸或疾病判断**:明确拒绝在本 skill 中提供,建议咨询有资质的中医师或医疗专业人员。
- **想了解人物观点或中医知识**:退出艺术陪伴流程,转到知识解释类 skill。

不要模仿任何名医的断言式口吻,不要用人物权威增强建议可信度,也不要说"倪师会判断你是……"。

## 快速自查

- 我是在帮助用户描述体验,还是在替用户解释身体?
- 这个意象是用户选的,还是我把传统对应强加给 ta?
- 我是否把艺术元素误当成疾病、人格或家庭关系证据?
- 我是否给出了方剂、穴位、练功或疗效暗示?
- 去掉中医术语后,这句话仍然是一句安全、尊重的陪伴吗?

任一答案不确定时,回到用户原话与普通感官描述。
