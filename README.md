# Art Therapy Skill

> 把难以说清的感受，变成一件可以看见、听见、带走的作品。

`art-therapy` 是一个面向 AI Agent 的表达性艺术陪伴 Skill。它不会在你说“最近有点乱”之后立刻丢给你一张所谓的治愈系图片，而是先陪你把感受说清一点，再将你自己的身体感受、颜色、质地与比喻，转化为图像、音乐、声音、文字或轻动态影像。

它把西方的表达性艺术疗法、Focusing、Somatic Experiencing、正念，与东方的中医身体意象、五行语言和道家养生动作放进同一套体验中，适合情绪疏解、自我探索、内在小孩、亲子表达与温和的创伤陪伴。

**这不是一个“帮你分析画”的工具，而是一段由你参与完成的创作式对话。**

## 为什么它不一样

### 先听懂你，再开始创作

Skill 会先用 3–8 轮弹性对话建立关系，理解发生了什么、感受落在身体哪里，以及它更像什么。只有到了合适的时机，才会邀请你开始艺术共创。

### 东西方身心智慧，不是术语拼盘

同一种感受，可以从不同的入口被看见。Skill 会根据用户自然使用的语言切换视角，而不是把一套理论强加给所有人：

| 身心语言 | 在对话中的作用 |
| --- | --- |
| Focusing | 为模糊的内在感受找到更准确的词、形状和名字 |
| Somatic Experiencing | 关注身体落点、感受强度与安全节奏，避免被情绪淹没 |
| 正念 | 用呼吸、感官与当下觉察为感受留出空间 |
| 中医身体意象 | 借“升、降、堵、散、冷、热、湿、燥”等气机与质地语言描述身体体验 |
| 阴阳与开合聚散 | 把向内/向外、打开/合上、聚拢/散开转成构图方向，而不是给人贴“偏阴偏阳”的标签 |
| 五行与四时 | 把木火土金水、春夏秋冬变成开放的材质与时间意象，含义始终由用户决定 |
| 道家养生动作 | 在出口阶段提供八段锦、鸣天鼓、搓涌泉、龟息法等简单身体动作，让体验落回日常 |

例如，同样是“胸口堵”，它既可以被 Focusing 追问为“更像什么形状”，也可以借中医气机意象分辨是“压下来、顶上来，还是卡在那里”，再通过正念或 Somatic 的方式回到脚底、呼吸和当下。

这些传统语言只被当作**体验的镜子**，不会变成“大师的判词”。它还可以用睡眠、呼吸、冷暖和当下精力做一个很轻的身体节律 check-in，但这些信息只用于决定本次对话要快一点、慢一点，还是少生成一个产物，不用于判断健康状态。

道家养生部分也只使用安全、日常、具体的身体动作，不涉及宗教实践、内丹功法或玄学承诺。方药、针灸、脉舌、六经辨证、“排毒/逼毒”和高强度练功都被明确隔离在 Skill 之外。

### 你的词，会成为整段体验的线索

如果你说“胸口像堵着一团热的湿棉花”，这句话不会在下一轮消失：

```text
对话：胸口像堵着一团热的湿棉花
  ↓
共创：让“热的湿棉花”成为画面中心，它是什么颜色？
  ↓
回看：最开始那种“湿”和“堵”，在现在的画面里有没有变化？
  ↓
带走：从这次意象里长出一句话，或一个 3 分钟内能完成的小行动
```

这条贯穿始终的“会话主线”，让生成结果真正来自你，而不是来自一套通用模板。

### 不止图像，但也不堆砌多模态

Skill 支持 6 种艺术形式与 5 种创作模态自由组合：

| 艺术形式 | 可以探索什么 |
| --- | --- |
| 曼陀罗 | 为混乱找到一个可以容纳它的结构 |
| 意象风景 | 把内在状态变成一片可进入、可变化的风景 |
| 象征物体 | 让难以直说的关系或感受拥有形状与位置 |
| 内在小孩 | 用安全、非评判的方式靠近曾经的自己 |
| 情绪色彩 | 不必解释，让颜色、质地和运动先替你表达 |
| 引导冥想 | 在文字、声音与环境音乐中完成一次安静停留 |

可用模态包括：**静态图像、动态影像、背景音乐、旁白语音、治疗性文字**。

每次只选择 **1 个主模态 + 最多 1 个增强模态**。情绪越重，产物越少。这里追求的不是“生成得多”，而是“有一件东西真的属于这次对话”。

### 你可以选择被怎样陪伴

开始时可以选择四种对话风格：

- 温和地听你说
- 像朋友聊天那样直接
- 少说话，但会问关键问题
- 尽量安静地陪着你

前期以倾听和确认感受为主；建立信任后，Skill 才会适度使用重构提问、意象跳转、温和面质和仪式性小行动，帮助你走到仅靠重复倾诉不容易到达的地方。

### 有主动引导，也有清晰边界

它会提出观察和邀请，但不会替你定义自己：

- 不做心理或中医诊断
- 不把画面武断归因到童年、父母或创伤
- 不承诺疗效，不替代专业心理咨询
- 不用“你应该积极一点”结束痛苦
- 识别到自伤、伤人、家暴、性侵或急性精神症状等危机信号时，立即停止创作流程，转入纯文字安全响应

## 一次体验会怎样展开

```text
Phase A  对话与倾听
         选择陪伴风格 → 说发生了什么 → 找到身体感受与个人意象
                    ↓
Phase B  艺术共创
         推荐适合的形式 → 一起补全意象 → 生成并进行有限迭代
                    ↓
Phase C  共同回看
         你先讲看见了什么 → Agent 再反馈观察 → 留下一件带走物
```

最终产物可能是一张画、一段音乐、一封写给自己的信、一段轻声旁白、一段有呼吸感的动态影像，或一个只需要几分钟的小小仪式。

## 适合什么时候使用

- “最近心里很乱，但我不知道怎么说。”
- “这件事已经过去了，我身体还是紧绷着。”
- “我想看看自己真正害怕的是什么。”
- “我总在关系里重复同一种感受。”
- “我想靠近内在小孩，但不想被过度分析。”
- “我想和孩子一起表达情绪，而不是逼他讲道理。”
- “我只想有人陪我安静一会儿。”

如果你的目标是学习心理学知识、获得医疗诊断，或单纯制作海报、MV、社交媒体封面，那么它并不是最合适的 Skill。

## 直接这样开始

导入 Skill 后，不需要准备专业术语。说一句真实的话就够了：

```text
最近心里有点乱，晚上也睡不好。
```

```text
我说不清是什么情绪，但胸口一直堵着。
```

```text
我想做一次内在小孩的艺术探索，请慢一点带我。
```

```text
今天不想分析，只想把这种感觉变成一种颜色和一段音乐。
```

```text
我更习惯东方的身体语言，能不能从“堵、沉、散”这些感觉陪我探索？
```

```text
我想和孩子一起做一个不需要画得好看的情绪表达练习。
```

也可以直接使用触发词：`艺术治疗`、`表达性艺术`、`情绪疗愈`、`心情画布`、`内在小孩`、`曼陀罗`、`身心地图`、`引导冥想`、`art therapy`、`expressive arts`。

## 设计原则

- **关系先于产物**：不把生图当成对话的捷径。
- **用户语言优先**：创作从用户自己的词生长出来。
- **东西方自然融合**：根据用户的感受选择合适入口，不展示流派、不堆砌术语。
- **观察而不解释**：描述所见，邀请联想，不替用户下结论。
- **少即是多**：限制迭代和模态数量，避免产物收集替代真实体验。
- **允许而不催促**：可以不回答、不创作、不积极，也可以随时停下来。
- **安全高于完整流程**：危机信号一旦命中，立即中断艺术生成。

## 重要声明

本项目是基于表达性艺术疗法理念设计的 **AI 对话陪伴工具**，不构成医疗诊断、心理治疗或专业咨询建议。中医相关表达仅作为身体意象使用，不用于辨证、处方或治疗；道家养生内容仅取安全、日常的身体动作，不涉及宗教实践、内丹术或疗效承诺。

如果你正在经历持续而强烈的痛苦，或有伤害自己、伤害他人的想法，请优先联系当地紧急服务、心理援助热线或可信任的专业人士。
